## 8. 关键结论与实盘建议 (Key conclusions & live-deployment notes)

- **表现 (performance):** full-period real-tick net **+$186k–$222k** on a $3,000 start (run-to-run spread is real: 10x compounding amplifies real-tick path differences), PF ~1.44, Sharpe ~2.0. Beats the unmodified V4 baseline ($171k).
- **盈利高度依赖复利后期 (profit is back-loaded):** 2026 alone makes the bulk; 2023 (capital-building) is roughly flat. Win rate is structurally ~42% — the edge is payoff asymmetry, not hit rate. 25/42 months are negative.
- **冷启动风险 (cold-start risk) — 最重要 (most important):** outcome depends heavily on WHEN you switch it on. Worst observed: a fresh $3,000 start into **2026-H1 → 69.6% equity drawdown**; 2023 / 2025-H1 starts barely break even at 40–46% DD. Plan psychologically and financially for a **40–70% equity drawdown in the first months**, especially with a fresh deposit.
- **本金保护 (principal):** worst principal erosion in the continuous run was −14.7% ($2,558). But on an unlucky cold start the equity (floating) drawdown reaches ~45–70%; only deposit risk capital.
- **无强平 (no liquidation)** occurred 2023–2026 at 1:1000, but **URF margin breaker is OFF** in this greedy build — there is no built-in catastrophe stop. 
- **更保守替代 (safer variant):** set `URF_Enable=true` and `ORCH_MaxBalanceScale=3` → ~$50k / ~20% max DD profile (≈4x less profit, ~half the DD). Use this if the 40–70% cold-start DD is unacceptable.
- **一键实盘 (one-click live):** the EA compiled defaults already equal this config; alternatively load `champion_greedy.set`.
